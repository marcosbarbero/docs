# Quartzon

A pocket LCD handheld from 1997 that never quite existed, rebuilt as an app. One monochrome panel, one dial, five games on it, and a single campaign running through all of them.

Free to play with ads; free play needs an internet connection so those ads can load.\*

## One machine, not five apps

Step the dial to choose a game. The panel never changes — same bezel, same segments, same two-tone screen — because this is one device, not a folder of apps. What changes is what is lit.

## One campaign, five terrains

The number that measures you belongs to the handheld, not to any one game. Clear levels anywhere and the total goes up, and later levels across the whole library open on that total. You cannot finish Quartzon by playing one game — and you are never forced into one you dislike.

250 levels in all.

## What is on it

- A snake that grows into its own tail
- A ball, a paddle, and a wall that has to come down
- A crossing where everything moves except you
- A picture hidden behind its own row and column counts
- A spreading front and a limited number of walls

## Features

- [**Premium Unlock**]({{ site.baseurl }}/quartzon/features/premium-unlock/) — one payment, no ads, plays offline, and every game added to the handheld later. Not a subscription.

## Never unfair

Every simulation is integer-deterministic: the same sequence of inputs always produces the same board. Every shipped level carries a winning line that is replayed and checked before release, so a level that cannot be finished cannot reach you.
