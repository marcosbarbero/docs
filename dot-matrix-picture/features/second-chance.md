# Second Chance

When the last life goes, the run is not over yet: you are offered one more, once per run.

The board is kept exactly as it was — every cell you filled, every cell you ruled out. The whole appeal is resuming the deduction you already did. An offer that handed back a blank grid would just be an offer to start again.

Free players watch a short video for it. Premium players are given it. The rule is the same either way: **paying changes the cost, not the game.**
