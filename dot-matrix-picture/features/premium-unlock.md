# Premium Unlock

One payment. No ads, ever, and the game plays with no connection at all — on a plane, in a tunnel, anywhere.

It is a one-time purchase, not a subscription: nothing renews and there is nothing to cancel. It can be bought from the main menu, from settings, or from the screen shown when a run ends, and **Restore purchase** sits beside the buy button on all of them.

Removing the ads also removes the advertising SDK's data collection described in the [Privacy Policy]({{ site.baseurl }}/dot-matrix-picture/privacy-policy/).
